## Features

- **Office-hours booking table.** One click listener on the `<tbody>` uses event delegation to book or cancel any slot, with an `aria-live` status line.
- **Feedback form validator.** It shows its own error messages with `role="alert"` and marks each bad field with `aria-invalid="true"`.
- **Keyboard friendly.** Every action works with `Tab`, `Enter` and `Space`, and focus rings are always visible.
- **Light and dark themes.** Colour tokens are written with `light-dark()` and `oklch()`, and styles are organised in CSS cascade layers.
- **Strict TypeScript.** The compiler turns `src/*.ts` into plain ES modules in `public/`, and a type error blocks the build.

## Getting started

**Requirements:** Node.js 18 or newer, plus VS Code with the Live Server extension (or any static server).

```bash
git clone https://github.com/<your-username>/web-engineering-lab.git
cd web-engineering-lab
npm install          # installs the TypeScript compiler (dev dependency only)
npm run build        # src/*.ts  →  public/*.js
```

Then open `public/index.html` with **Live Server** (port 5500). You can also serve the folder another way:

```bash
npx serve public     # or: python -m http.server 5500 --directory public
```

| Script | Command | What it does |
| --- | --- | --- |
| `npm run build` | `tsc` | Type-checks and writes JavaScript to `public/` |
| `npm run typecheck` | `tsc --noEmit` | Type-checks only; prints nothing when the code is clean |

## Part A – Reading and porting legacy jQuery

The validator was first written the way much production code still looks: `var` everywhere, `$.trim`, HTML built from strings, and `indexOf`. It loaded jQuery from the CDN, pinned to **3.7.1** because jQuery 4 removed `$.trim`.

<p align="center">
  <img src="docs/screenshots/legacy-jquery.png" alt="Legacy jQuery validator in VS Code" width="850" />
</p>

I translated each call before porting it (full notes in [`LEGACY-NOTES.md`](LEGACY-NOTES.md)):

| jQuery | Native JavaScript |
| --- | --- |
| `$(document).ready(fn)` | `<script type="module">` (already deferred) |
| `$("#name").val()` | `document.querySelector("#name").value` |
| `.after('<span class="error">…</span>')` | `createElement("span")` + `textContent` + `input.after(span)` |
| `$(".error").remove()` | `querySelectorAll(".error").forEach((el) => el.remove())` |
| `.text(msg).hide().fadeIn(400)` | `status.textContent = msg` (fade dropped – animation belongs in CSS) |
| `$form[0].reset()` | `form.reset()` |

The native port keeps the same behaviour and adds `role="alert"` and `aria-invalid`. It also removes 88 kB from every page load:

## Part B – TypeScript foundations

### Compiler setup

```jsonc
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "strict": true,          // null checks, no implicit any
    "rootDir": "src",
    "outDir": "public",
    "noEmitOnError": true    // a type error means no JavaScript is written
  },
  "include": ["src"]
}
```

### What the compiler found

After `git mv` of the three scripts into `src/`, the first typecheck reported **27 errors in 4 files**. None of them showed up when the code ran in the browser.

<p align="center">
  <img src="docs/screenshots/typecheck-27-errors.png" alt="First typecheck: 27 errors in 4 files" width="850" />
</p>

Two of the errors were especially useful:

- **`'event.target' is possibly 'null'`.** The type is `EventTarget | null`, not an element. The fix narrows it with `if (!(target instanceof Element)) return;`.
- **`Cannot redeclare block-scoped variable 'status'`.** Without an `import`, `feedback.ts` was a *global script*, so its `status` clashed with the built-in `window.status`. Adding `import { getRequired } from "./utils.js"` turned it into a module.

### Types used

| Concept | Example in this repo |
| --- | --- |
| Annotation | `delay(ms: number): Promise<void>` |
| Interface | `interface Slot { day; start; end; room }` |
| Union + narrowing | `closest()` → `HTMLButtonElement \| null` → checked before use |
| Generic | `getRequired<HTMLInputElement>("#name", form)` |

```ts
export function getRequired<T extends Element>(selector: string, root: ParentNode = document): T {
  const element = root.querySelector<T>(selector);
  if (element === null) throw new Error(`Missing element: ${selector}`);
  return element;
}
```

### Structural typing

An object that was never declared as a `Slot` still counts as one if it has the right shape. Missing properties are caught at compile time:
